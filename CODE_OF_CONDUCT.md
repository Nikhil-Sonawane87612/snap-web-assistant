# Code of Conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/) Code of
Conduct, version 2.1.

Be respectful, constructive, and considerate. Harassment, discrimination,
or abusive behavior will not be tolerated. Maintainers may remove
contributions or ban contributors who violate these standards.

For enforcement, contact the maintainer via the repository's issues or
security channel.
